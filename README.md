## 📜 租賃生活公約重點 (House Rules Summary)

1. **全面禁菸**：室內、前後陽台及大樓公共區域一律**嚴禁吸菸**（含電子煙）。
2. **禁養寵物**：為維持原木家具品質與環境清潔，原則上不開放寵物；特殊情況需事先徵得同意並簽署寵物附約。
3. **禁止轉租與違法行為**：嚴禁轉租、分租、作日租套房 (Airbnb)，嚴禁賭博、吸毒或任何違法用途。
4. **禁止室內拜拜**：禁止安設神明桌或於室內燃燒金紙，確保消防安全與牆面整潔。
5. **社區安寧時間**：每日 22:00 至翌日 08:00 請降低音量，維護鄰里寧靜。
6. **垃圾集中處理**：請依社區分類規定放置於地下室/集中清運處，免追垃圾車。
