## 🌟 核心計算財務參數與預設值

1. 💰 **每月目標/基礎租金**：預設 **NT$ 23,000 / 月**
2. 🏦 **每月房貸本息支出 (利息+本金)**：預設 **NT$ 24,000 / 月**
3. 🏢 **社區管理費**：預設 **NT$ 3,000 / 月**
4. 🔨 **裝潢傢俱與建置成本**：預設 **NT$ 80 萬元** (800,000)
5. ⏳ **折舊攤提年限**：預設 **5 年** (60 個月，月攤提 NT$ 13,333 / 月)
6. 🎯 **五大適合出租定價矩陣**：
   - 🛡️ **方案 A・房貸+管費現金流打平價**：`房貸 $24,000 + 管費 $3,000` = **NT$ 27,000 / 月**（零自掏腰包，由租客供養房貸積累房產淨值）
   - 💎 **方案 B・全成本保本底線價**：`房貸 $24,000 + 管費 $3,000 + 裝潢月攤提 $13,333` = **NT$ 40,333 / 月**（5年內全額收回 80 萬裝潢款，並繳清房貸與管費）
   - 👑 **方案 C・黃金全額回本價（旗艦推薦）**：`實拿 $23,000 + 管費 $3,000 + 全額月攤提 $13,333` = **NT$ 39,333 / 月**（抵扣房貸後每月正現金流 $12,333 兼收回裝潢）
   - ⚡ **方案 D・市場甜蜜點（50% 裝潢分擔）**：`房貸 $24,000 + 管費 $3,000 + 50% 裝潢溢價 $6,667` = **NT$ 33,667 / 月**（兼具高 CP 值與快速滿租）
   - 🌐 **方案 E・外商商務高階全包價**：`全成本 + 車位 + 光纖 + 定期清潔 + 水電` = **NT$ 48,000 / 月**
